# 검증 기록

검증일: 2026-10-15. 이 PC에서 실행했으며 실제 업무 회의나 사용자의 사적 음성을 테스트 자료로 사용하지 않았다.

## 환경

Windows / Ryzen 9 9955HX3D (16C/32T) / RAM 약 31.2 GiB / RTX 5070 Ti Laptop 12GB / NVIDIA 617.14. 기본 CPU 추론 4스레드, 화자 모델 2스레드.

## 확인한 동작

- 저장·이름 일괄 반영·오디오 삭제 조건·장치 오류·중단 복구·무음 루프백 종료 등 unittest 15개 통과.
- 공개 한국어 음성 → 한국어 특화 CTranslate2 INT8 모델 → 실제 전사/화자 → Qwen 회의록 → DOCX/TXT 생성 → 오디오 자동 삭제: 소스와 EXE 모두 통과.
- 실제 Qt 버튼의 시작/종료/자동 처리/이름 변경 동작 통과. 마이크 대신 공개 음성 파일을 주입해 검증.
- 실제 WASAPI 기본 마이크와 시스템 루프백 장치 open/start/stop 통과. 이 검사는 음성을 읽거나 파일로 저장하지 않음.
- 실제 무음 루프백의 입력 버퍼가 0임을 확인하여, 버퍼가 있을 때만 읽는 방식으로 변경. 상대방이 침묵할 때도 종료 요청에 응답한다.
- GPU 미사용 CPU 4스레드 경로로 한국어 샘플 전사 성공. 3.53초 파일에 약 11.22초가 걸려 CPU 대체 경로에서는 실시간 표시가 지연될 수 있다. 디스크 녹음은 계속되며 종료 후 남은 구간을 처리한다.
- 한국어 특화 모델의 짧은 발화 끝에 생성된 무시간 환각 문장을 발견. 0.08초 미만에 여러 글자가 붙는 구간을 배제한 뒤 해당 공개 샘플에서 재현되지 않음. 모든 환각이 제거된다는 의미는 아님.
- 한영 모델로 한국어 3.53초와 영어 11초 파일을 각각 인식하고 서로 다른 화자로 배정. 한 문장 안의 언어 전환 정확도를 평가한 것은 아님.
- 명시적으로 만든 개발 회의 전사로 제안/승인/미결/담당자/기한/후속 일정을 구분하는 JSON 생성과 Word 저장을 확인.
- Windows 150% 화면 배율에서 첫 창 크기 보정, 목록 폭, 설정 스크롤 확인.

## 처리 속도 및 자원 표본

초기 CUDA 준비 비용이 한 번 약 18.5초 발생했다. 이후 새 프로세스 첫 샘플은 약 1.8~2.0초, 준비된 모델에서는 다음과 같았다.

| 검사 | 음성 길이 | 처리 시간 |
|---|---:|---:|
| 한국어 특화 모델, 동일 공개 발화를 반복한 파일 | 12.58초 | 약 1.68초 |
| 한국어 특화 모델, 재처리 | 3.53초 | 약 0.76초 |
| 한영 모델, 한국어 파일 | 3.53초 | 약 1.79초 |
| 한영 모델, 영어 파일 | 11.00초 | 약 1.06초 |

아래는 짧은 한국어 파일 1개를 패키징된 EXE로 처리하며 0.3초 간격으로 관찰한 표본이다. 프로세스 시작·모델 로딩을 포함한다. GPU 값은 데스크톱 등 다른 프로세스를 포함한 **GPU 전체 사용량**이다. RAM은 앱 작업 프로세스와 그 자식의 RSS 합계이며 GUI 상주분은 별도다.

| 단계 | 전체 시간 | 관찰 최대 RAM | GPU 전체 최대 사용량 | 전체 CPU 평균 환산 |
|---|---:|---:|---:|---:|
| 한국어 전사/화자 | 6.76초 | 0.91 GiB | 1,897 MiB | 약 1.93% |
| 로컬 회의록/Word/TXT | 9.29초 | 5.49 GiB | 6,112 MiB | 약 1.97% |

CPU 평균은 프로세스 CPU 시간 합계 / 경과 시간 / 32논리CPU로 계산한 표본이다. 순간 최대치나 CPU 사용 상한을 뜻하지 않는다. GPU 로딩과 브라우저 등의 상태에 따라 측정치는 달라진다. 최종 EXE의 재검사 결과는 로컬 `test-output/exe_metrics.json`에 기록한다.

## 검증 범위의 한계

실제 여러 한국인의 긴 회의, 방언·원거리 마이크·잡음·겹침 발화, 몇 시간 연속 녹음, 브라우저 다수 탭과의 장시간 동시 사용에 대한 정확도/스트레스 검증은 아직 하지 않았다. 화자 인원은 추정이며 실제 회의에서 확인해야 한다. 이 기록은 특정 환경의 기능·표본 성능 확인이며 최고 정확도나 무오류를 보장하지 않는다.
