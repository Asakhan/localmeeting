# 2026-10-15 전사 오류 수정

프로그램명: 아사검의 회의록 / Khan's Minutes.

## 확인한 현상

- 저장된 사용자 전사에서 `질문해 주시겠어요?아버지 뭐하시노.`가 11.331~11.471초(0.14초)에 배치되어 있었다. 0초 길이의 단어도 존재했다.
- 기존 공개 음성 테스트 결과에도 `아버지 뭐하시노.`가 3.48~3.50초에 덧붙었다. 특정 사용자 발언에만 나타나는 문제가 아니었다.
- 기존 한국어 경로는 komix medium 모델을 사용했고, 문장 전체 길이만 검사하여 긴 문장 끝에 붙는 잘못된 단어 정렬을 놓쳤다.
- 사용자 원음은 완료 후 자동 삭제되어 `테스트/게스트`, `은혜`, `헬미`를 원음과 대조할 수 없다. 해당 단어들의 개별 원인은 확정하지 않는다.

## 적용

- 한국어/혼합 언어 모두 large-v3 INT8을 사용한다.
- 발화 구간과 단어별 시간·신뢰도를 검사한다. 무음, 0초 길이, 지나치게 빠른 정렬, 정렬 없는 문장을 제외한다. 낮은 단어 신뢰도는 `[청취 불명확]`으로 표시한다.
- 용어 힌트를 initial_prompt 대신 hotwords로 전달한다.
- 특정 단어를 금지하거나 `게스트`를 무조건 `테스트`로 치환하지 않는다.
- 창 제목, 앱 이름, 실행 파일 버전 정보, 바로가기 설치 스크립트에 새 이름을 반영한다. 기존 설정 저장 경로는 유지한다.

## 검증

- `python -m unittest discover -s tests -q`: 26개 통과.
- `python verify_stt.py`: 기존 공개 한국어 음성에서 본문 `그는 괜찮은 척하려고 애쓰는 것 같았다.`만 출력. 덧붙던 문장은 사라졌다.
- 이 결과는 원음이 삭제된 사용자 녹음의 네 사례가 모두 해결되었다는 증거는 아니다. 새 녹음에서 추가 확인이 필요하다.
